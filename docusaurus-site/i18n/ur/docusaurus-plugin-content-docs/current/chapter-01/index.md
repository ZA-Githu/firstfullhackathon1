# باب اول: AI-Native ترقی کا تعارف

یہ باب AI-Native ترقی کی بنیادی سوچ کو قائم کرتا ہے۔ آپ سیکھیں گے کہ ایک ٹیم یا نظام کو واقعی AI-Native کیا بناتا ہے — نہ کہ صرف AI-Assisted — اور AI تعاون کے گرد ورک فلو دوبارہ تعمیر کرنے سے حاصل ہونے والے مرکب فائدے کو سمجھیں گے۔

## اس باب کے موضوعات

- **موضوع ۱:** AI-Native ترقی کیا ہے؟
- **موضوع ۲:** AI-Assisted بمقابلہ AI-Native: بنیادی فرق
