## ابھرتے ہوئے پیٹرنز اور ٹولز

سب سے اہم آرکیٹیکچرل تبدیلی AI ایجنٹس کا آپریٹنگ سسٹم کے طور پر کام کرنا ہے جو مخصوص ماڈلز اور ٹولز کو orchestrate کرتے ہیں۔

### آپریٹنگ سسٹم کے طور پر ایجنٹس

ایک orchestrator ایجنٹ پلاننگ، تحقیق، عمل درآمد، تشخیص، اور مواصلت کے ایجنٹس کو ہم آہنگ کرتا ہے۔ ہر ایک کے پاس مخصوص ٹولز، ایک اچھی طرح سے تعریف شدہ انٹرفیس، اور ڈومین سے متعلق میموری ہے۔ انسان اعلیٰ سطح کا ارادہ طے کرتا ہے اور اہم فیصلوں کی منظوری دیتا ہے۔

```
TextbookMasterAgent (orchestrator)
├── RAGQuerySkill       → کتاب کا مواد تلاش کریں
├── ChapterGenerationSkill → ابواب لکھیں/پھیلائیں
├── PersonalizationSkill   → سیکھنے والے کے پروفائل کے مطابق ڈھالیں
├── TranslationSkill       → اردو ترجمہ
└── IngestionSkill         → نیا مواد embed کریں
```

یہ بالکل وہی طریقہ ہے جس سے اس کتاب کا بیک اینڈ بنایا گیا ہے — `TextbookMasterAgent` پانچ دوبارہ استعمال کے قابل مہارتوں کو Claude کے tool-use API کے ذریعے orchestrate کرتا ہے۔

### Context Windows اور Multimodal AI

128K سے 1 ملین tokens تک context windows سسٹم ڈیزائن کو دوبارہ شکل دیتی ہیں:

| Context کا سائز | بہترین استعمال |
|---|---|
| 8K–32K | معیاری چیٹ، کوڈ جائزہ |
| 128K | لمبی دستاویزات، مکمل کوڈ بیسز |
| 1M | پوری کتابیں، ویڈیو تجزیہ |

لمبا context RAG کو ختم **نہیں** کرتا۔ لمبا context اس وقت استعمال کریں جب درستگی سب سے زیادہ اہم ہو اور RAG اس وقت جب پیمانہ اور لاگت سب سے زیادہ اہم ہو۔

### Vision-Language-Action (VLA) ماڈلز

VLA ماڈلز طبیعی AI کے لیے اگلی سرحد ہیں۔ وہ بصری ان پٹ لیتے ہیں، زبان کی ہدایات کو سمجھتے ہیں، اور روبوٹ کے اقدامات کو آؤٹ پٹ کرتے ہیں۔

```
کیمرہ ان پٹ → ویژن انکوڈر
                    ↓
زبان کی ہدایت → لینگویج ماڈل → ایکشن آؤٹ پٹ → روبوٹ
```

اہم VLA ماڈلز:
- **RT-2** (Google): roboٹکس ٹرانسفارمر، ویب پیمانے کی ٹریننگ
- **OpenVLA**: اوپن سورس، Jetson Orin Nano پر چلتا ہے
- **π0** (Physical Intelligence): چست ہیرا پھیری

### کوڈ جنریشن میچورٹی کرو

ٹیمیں پانچ مراحل سے گزرتی ہیں:

1. **Autocomplete** — IDE میں tab تکمیل
2. **فنکشن جنریشن** — ایک وقت میں ایک فنکشن تیار کریں
3. **کمپوننٹ جنریشن** — مکمل کمپوننٹس تیار کریں
4. **فیچر جنریشن** — spec سے پورے فیچرز تیار کریں
5. **سسٹم جنریشن** — ارادہ سے سسٹمز تیار کریں

اچھی طرح سے مخصوص فیچرز کے لیے Leading AI-Native ٹیمیں مرحلہ 5 تک پہنچتی ہیں۔ ٹولز پر نہیں، پیٹرنز پر شرط لگائیں۔ پیٹرنز باقی رہتے ہیں جیسے مخصوص ٹولز ہر 18 مہینوں میں تبدیل ہوتے ہیں۔
