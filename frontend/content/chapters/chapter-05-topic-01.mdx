## Emerging Patterns and Tools

The most significant architectural shift is AI agents acting as operating systems orchestrating
specialised models and tools. An orchestrator agent coordinates planning, research, implementation,
evaluation, and communication agents. Each has specific tools, a well-defined interface, and
domain-relevant memory. The human sets top-level intent and approves critical decisions.

### Context Windows and Multimodal AI

Context windows from 128K to one million tokens reshape system design. Long context does not
eliminate RAG. Use long context when precision matters most and RAG when scale and cost matter
most. Multimodal AI handles vision, audio, and code in production. The Claude API supports
images directly in the messages array for tasks like automated accessibility analysis.

### The Code Generation Maturity Curve

Teams progress through five stages: autocomplete, function generation, component generation,
feature generation, and system generation from intent. Leading AI-Native teams reach Stage 5 for
well-specified features. Humans operate at the level of intent and evaluation, not implementation.
Bet on patterns not tools. The patterns remain as specific tools change every eighteen months.
